# lui M6 设计方案：TS 脚本引擎（TypeScript 子集，纯 Pascal 自研）

> 状态：设计已评审通过（2026-09-11），三个前置决策已确认（运行时 / TS 范围 / 能力范围），见 §1。
> **实施进度**：M6-1（内核）、M6-2（TS 前端与 ES6）、**M6-3（引擎集成）已完成**；M6-4（demo 与文档）部分完成。
> 异步能力（Promise / 完整 async-await / 定时器 / 真实 I/O）见配套文档 **《M6-异步设计.md》**（P0、P1 已完成）。

## 1. 背景与现状

M1–M5 已完成（tests 277 项全绿）。文档 ADR 4 曾写"脚本引擎(PascalScript)留 v2"——
本次把该承诺落地为 **TypeScript 子集脚本引擎**，并作为**后续所有功能绑定脚本的载体**。

已确认的三个决策（本方案前提）：

| 决策 | 结论 |
| --- | --- |
| 运行时 | **自研子集解释器**（纯 Pascal，零第三方依赖）；放弃 QuickJS DLL（二进制依赖）与 BESEN（ES5-only、停更、LGPL） |
| TS 范围 | **类型擦除 + ES6 子集（含类）**；不做类型检查（那是 tsc 的事） |
| 能力范围 | 基线（事件处理 + 运行时 DOM）+ **定时器** + **动态事件绑定**；自定义元素后置 |

脚本层需要接入的现有挂点（已核实）：

| 接入点 | 现有代码 |
| --- | --- |
| 事件分发 | `xui_engine.pas:417 DispatchEvent` / `:449 DispatchKind`（绑定命中即消费） |
| 绑定解析 | `ResolveBindings`（`xui_engine.pas:373` 附近）；`TXuiEventBinding.HandlerName` 保留原始方法名 |
| 宿主方法解析 | `xui_events.pas:126 XuiResolveMethod`（MethodAddress）；`TXuiEvent`（`:27`）、`TXuiEventKind`（`:21`）、属性名表（`:52`） |
| 运行时 DOM | `xui_engine.pas:904 AddElement`、`SetText/SetClass/SetDisabled/RemoveElement/ClearChildren` |
| 生命周期 | `LoadFromFile/LoadFromString` → `ApplyNodeDataRecursive` → 脚本求值（DOM 就绪后）；`RebindEvents`（`:1016`） |
| 热重载 | `ReloadChangedFiles`（`:319`）、`RecordDocSources`（`:281`）、`FHotReload`/`FDocWatch` |
| 刷新驱动 | `Tick`/`NeedsTick`（`:886`）+ 宿主 `TTimer`（M5 已按需启停） |
| XML 特判范本 | `xui_xml.pas:151 BuildInclude`（`<include>` 不产生节点 + 依赖收集） |
| 文档来源 | `xui_dom.pas:52 TXuiDocument`（`SourceFile`/`Dependencies`） |

## 2. 总体架构与分层

```
XML/宿主事件 ──► TXuiEngine ──(DispatchEvent 第二来源)──┐
        │ 加载                          │ 动态绑定/Timer
        ▼                               ▼
   TXuiDocument.Scripts ──────► xui_script（门面）
                                ├─ 编译缓存 / 求值 / 调用 / 指令预算 / 错误
                                ├─ 原生函数注册（后续功能的统一挂点）
                                └─ GC 根管理
                                       │
                     xui_js_token ─► xui_js_parser ─► xui_js_runtime
                     （词法）        （语法 + TS 擦除）   （AST 解释 + 内建）
                                       ▲
                          xui_script_dom（宿主对象桥：document/node/event）
```

**分层规则（防循环引用）**：
- `xui_js_*` 与 `xui_script` **不依赖 LCL/引擎**（纯逻辑，可直接进 runtests）；
- `xui_engine` 只依赖 `xui_script` 的**抽象**（`TXuiScriptHost` 虚基类 + 回调类型），不依赖具体 DOM 桥；
- `xui_script_dom` 是 leaf 单元（uses `xui_engine` + `xui_script`），由 `xui_host` 装配；
- 不加载脚本时零开销（解释器不参与任何现有路径）。

## 3. 方言规范（TS 子集白名单，冻结）

**语法支持**：

| 分组 | 内容 |
| --- | --- |
| 类型擦除 | `: T` 注解、`as T`、泛型参数表 `<T>`、`interface`/`type` 声明（整体丢弃）、`enum`（数字/字符串 → 对象+常量）、可选 `?`、非空断言 `!`、`public/private/readonly` 修饰符 |
| 声明 | `var/let/const`、函数声明/表达式、箭头函数（含词法 `this`）、类（constructor/方法/实例字段/单继承/`super`） |
| 表达式 | 算术/比较/逻辑/位运算、`?:`、`&&`/`||`/`??`、可选链 `?.`、模板串 `` `a${x}` ``、解构（对象/数组，默认值+重命名）、展开（数组/对象） |
| 语句 | `if/else`、`while`、`do..while`、`for(;;)`、`for..of`、`try/catch/finally`、`throw`、`break/continue`、`return` |
| 内建 | `Math`、`String/Array/Object/JSON` 常用方法、`console.log/error`、`parseInt/parseFloat/isNaN` |
| 标识符 | ASCII 字母/数字/`_`/`$`，且**允许中文字节**（`let 计数 = 0` 合法） |

**不支持（写入文档不支持清单）**：`import/export` 模块、Generator、
装饰器、`namespace`、**类型检查**（类型仅擦除）、正则/`RegExp`、`Date`、`BigInt`、`Map/Set`、
`Proxy/Reflect/Symbol`、`get/set` 访问器、私有字段 `#x`、内联 `<script>` 文本。

> **注**：`async/await`/`Promise`/定时器/真实 I/O 原列于本节，现已在《M6-异步设计.md》中设计并分阶段实施
> （P0、P1 已完成：**Promise 与微任务已可用**；定时器见 P2、async/await 见 P3、真实 I/O 见 P4）。
> 未落地条目在代码层面仍然有效。

**刻意语义偏差（必须文档化 + 测试覆盖）**：
- `string.length` 与索引按 **UTF-8 码点**计数（非 JS 的 UTF-16 code unit）——面向中文场景的刻意选择，
  与 `xui_text.pas` 既有 `Utf8Length/Utf8NextIndex` 工具一致；
- 数字统一 double；整数值打印不带 `.0`；
- 支持简化 ASI（换行处若下一 token 不能续接则结束语句；`return/break/continue/throw` 后换行立即结束），
  文档建议显式写分号；
- 事件处理器返回值被忽略（不支持阻止冒泡语义，与 v1 "绑定命中即消费"一致）；处理器内 `this` 未绑定。

## 4. 脚本 API（宿主对象面）

**全局对象**：
```ts
document.find(id: string): Node | null    // 文档入口
document.root: Node
ui.version: string
ui.now(): number                          // 单调毫秒（Tick 时钟）
ui.setTimeout(fn, ms): number             // 定时器（接入现有 Tick）
ui.clearTimeout(id) / ui.setInterval(fn, ms) / ui.clearInterval(id)
ui.reloadScripts()                        // 手动重载脚本（调试）
```

**Node 对象**（桥接 `TXuiNode`，属性写入统一路由到引擎 API 保证样式/布局失效正确）：
```ts
node.id / node.tag: string                // 只读
node.text: string                         // 读写 → Engine.SetText（input 即其 value）
node.class: string                        // 读写 → Engine.SetClass
node.disabled: boolean                    // 读写 → Engine.SetDisabled
node.scrollTop: number                    // 读写 → 置布局脏
node.count: number                        // 子节点数（只读）
node.find(id): Node | null                // 子树查找
node.on(type, fn) / node.off(type, fn)    // 动态事件绑定（脚本侧注册/注销）
node.add(xml: string): Node | null        // → Engine.AddElement（支持 include 片段）
node.remove() / node.clear()
node.hasClass(name): boolean
```

**事件对象**（处理器第一参数）：
```ts
{ type: string, node: Node, x: number, y: number,        // 指针类
  key: number, shift: {shift,ctrl,alt}, text: string }   // 键盘/文本类
```

**原生注册（"后续功能绑定脚本"的统一机制）**：
```pascal
type TXuiScriptNativeFunc = function(const AArgs: TXuiScriptArgs): TXuiScriptValue of object;
Script.RegisterNative('ui.now', @NowImpl);   // 路径式注册，自动建中间对象
```
后续 lui 新能力（图表、请求、存储…）都通过该接口挂到全局命名空间，脚本侧零改动即可调用。

**事件绑定解析顺序**（`DispatchEvent` 扩展，惰性解析）：
① 宿主 published 方法（`MethodAddress`，保持 login 页行为不变）→
② **脚本全局同名函数** → ③ 节点行为 `HandleEvent` → ④ `OnEvent` 兜底。
动态绑定（`node.on`）直接注册函数句柄，不参与名字解析。

## 5. 关键设计决策（ADR 12–15）

| ADR | 决策 | 理由与代价 |
| --- | --- | --- |
| 12 运行时 | **自研 TS 子集解释器**（树遍历），AST 编译结果缓存 | 零依赖（N1）+ 与引擎对象桥接零摩擦 + 可全量单测；代价：工作量最大（本项目至今最大一块），解释执行性能有限（事件驱动 + 指令预算可接受，后续可加字节码） |
| 13 方言 | **TS 类型擦除 + ES6 子集**，白名单冻结（§3） | 类型由 tsc 检查、运行时只擦除（esbuild/sucrase 同思路）；代价：不支持模块与异步，复杂类型（装饰器/命名空间）直接报错 |
| 14 分层 | 脚本内核零 LCL 依赖；引擎只依赖抽象 `TXuiScriptHost`；DOM 桥为 leaf 单元 | 内核可单测、可替换后端（未来换 QuickJS 也走同一抽象）；代价：多一层桥接的类型映射 |
| 15 绑定 | RTTI 优先、脚本次之、**惰性解析**；`node.on` 为一等 API | 兼容 M4/M5 既有页面零改动；脚本可重载后立即生效（无需重解 XML） |

## 6. 分阶段实施

### M6-1 脚本内核（纯逻辑，无 LCL）
- `xui_js_token.pas`（新建）：词法——数字/字符串/模板串/标识符（含中文）/注释/关键字/运算符；不做正则
- `xui_js_parser.pas`（新建）：Pratt 表达式 + 递归下降语句 → AST；简化 ASI；错误带 文件:行:列
- `xui_js_runtime.pas`（新建）：值模型、环境链与闭包、最小原型链、内建（Math/String/Array/Object/JSON/console）、
  `throw/try/catch/finally`、**标记-清除 GC + 根集**、**指令预算**
- 规模约 2500 行；测试约 60 项（表达式/语句/闭包/原型/数组/字符串/中文/异常/GC/预算）

### M6-2 TS 前端（类型擦除）与 ES6 语法
- 在 parser 内完成：类型注解/泛型表/`as`/`interface`/`type` 擦除、`enum` 降级为对象、
  `?`/`!`/修饰符处理
- ES6：箭头函数（词法 `this`）、模板串、解构（含默认值/重命名）、展开、可选链、`??`、`for..of`、
  类（constructor/方法/实例字段/单继承/`super`）
- 规模约 1000 行；测试约 30 项
- **风险最高**：类与 `super`；受阻时降级为"类不支持继承"，并同步不支持清单

### M6-3 引擎集成
- `xui_script.pas`（新建）：门面——编译/求值/调用/原生注册/根管理/预算/错误类型（`TXuiScriptError`）
- `xui_script_dom.pas`（新建）：宿主对象桥（document/node/event；属性写入路由到引擎 API）
- `xui_dom.pas`：`TXuiDocument` 增 `Scripts: TStringList`（脚本来源，供热重载监测）
- `xui_xml.pas`：`<script src="app.ts"/>` 特判（不产生节点、按序收集，范本 = `BuildInclude`）
- `xui_engine.pas`：
  - `Script` 属性（懒创建门面，装配宿主桥）；文档加载完成后按序求值
  - `DispatchEvent` 第二来源（脚本全局函数）+ 动态绑定表（`node.on`）
  - 定时器表 + `Tick` 派发 + `NeedsTick` 计入待触发定时器（宿主 Timer 自动启停，复用 M5 机制）
  - 脚本热重载：`FScrWatch`（路径→FileAge）→ 变化则**重新求值 + 重绑，DOM 保留**（与 M5 的 CSS 重载同语义）
  - `OnScriptError` 回调（文件/行列/消息/阶段）；`RebindEvents`/`ClearChildren`/文档重建时同步 Reset 脚本侧引用
- `xui_host.pas`：装配 DOM 桥；脚本错误写入 `script-error.txt` + 可选写入 `#msg` 节点
- 测试约 35 项（脚本改 DOM 后样式/布局生效、事件派发、动态绑定、定时器推进、错误隔离与预算、
  脚本热重载保留 DOM、绑定解析顺序）

### M6-4 demo 与文档
- `demo/todo.ts`（新建）+ `todo.xml` 加 `<script src="todo.ts"/>`：把 Todo 页处理器迁到脚本
  （切换完成态/删除/添加/计数），保留 login 页的 RTTI 写法作对照
- `demo/script.xml` + `demo/script.ts`（新建页）：综合演示——动态绑定、`setInterval` 计数器、
  运行时增删节点、`node.text` 读写
- `demo1.lpr`：加 `script` 页参数；`watch` 模式下脚本热重载生效
- `docs/设计方案.md`：ADR 12–15、§4 增"脚本方言白名单"、§7 M6 里程碑与完成记录、§9 工程结构、
  §不支持清单

## 9. 明确不做（首轮，文档同步）

- 模块系统（`import/export`）、`async/await`/Promise、Generator、装饰器、`namespace`、类型检查
- 正则/`RegExp`、`Date`、`BigInt`、`Map/Set`、`Proxy/Reflect/Symbol`、`get/set` 访问器、私有字段
- 内联 `<script>` 文本（XML 转义不友好）、npm 生态、字符串按 UTF-16 计数（刻意偏差，见 §3）
- 脚本沙箱：脚本为本地可信代码，不构成安全边界（文档注明，与 CSS/XML 同级信任）
- 自定义元素/组件化、字节码 VM、调试器（后置按需）

## 10. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 解释器工作量大（本项目至今最大一块） | 严格白名单冻结 + 4 阶段可分批交付验收；内核纯逻辑可单测；类/super 受阻可降级为"无继承" |
| 解释执行性能（每事件/每帧） | 事件驱动、脚本轻量；指令预算保护；AST 编译结果缓存（热重载只重解析变化文件）；后续可加字节码 |
| GC 与引擎对象互引用（悬垂/泄漏） | 桥对象对 `TXuiNode` 弱引用；引擎持有的脚本值走根集登记；DOM 重建/删节点时 `Reset`（沿用 M5 纪律） |
| 偏离 JS 语义（字符串按码点） | 文档白名单显著标注 + 中文用例测试覆盖（复用 `Utf8Length/Utf8NextIndex`） |
| ASI 边界情况 | 简化规则 + 文档建议写分号 + 覆盖常见写法的测试 |
| 脚本错误拖垮应用 | 编译期/求值期/调用期错误全部经 `OnScriptError` 上报并中止当次调用；死循环由指令预算兜底 |
